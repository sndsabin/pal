Get pal

First launch

Unsigned

Releases are currently unsigned, so your operating system may ask you to approve pal the first time you open it.

macOS

First launch

macOS may block the app stating it “cannot be opened because it is from an unidentified developer.”

How to run

  1. 1. Open System Settings → Privacy & Security .
  2. 2. Scroll down to the Security section.
  3. 3. Find the notification for pal and click Open Anyway.
  4. 4. Enter your password or use Touch ID to confirm.
Apple guide ↗

Windows

First launch

Windows Defender SmartScreen may show “Windows protected your PC.”

How to run

  1. 1. Click More info inside the blue window.
  2. 2. Click Run anyway at the bottom.
